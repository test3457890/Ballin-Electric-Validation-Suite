## Screenshot policy

Once the application is built, add genuine screenshots captured from the running application. Label the software version, operating system and whether readings came from physical hardware or a fixture. Remove sensitive customer information, machine identifiers, keys and unrelated desktop content. Preserve existing concept references and clearly differentiate them from implementation evidence.
