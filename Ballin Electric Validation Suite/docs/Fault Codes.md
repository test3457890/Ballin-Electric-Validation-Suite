# Fault code catalog

Catalog version 1.0.0. Generated from `be-core/src/codes.rs` (`bevalidate faults --format json`). Codes are original Ballin Electric codes, not vendor codes. A code records a confirmed observation; *possible causes are hypotheses, never a diagnosis*.

| Code | Severity | Title | Meaning | Possible causes | Next safe steps |
| --- | --- | --- | --- | --- | --- |
| BE-CPU-001 | error | CPU arithmetic mismatch | A verified integer or floating-point computation produced a result different from its known answer or reference. | CPU core instability; System memory error; Memory controller; Unstable firmware/overclock settings; Thermal or power instability | Repeat the verified workload on the same core; Run system memory pattern tests; Confirm firmware settings are at approved defaults; Review hardware error logs (MCE/WHEA) |
| BE-CPU-002 | error | CPU worker inconsistency | Parallel workers computing the same deterministic workload disagreed with each other. | Core-specific instability; Cache error; Memory error | Re-run with per-core affinity; Inspect machine-check logs; Run memory tests |
| BE-CPU-003 | warning | Machine-check events reported | The operating system recorded machine-check / hardware error events. | CPU, cache or memory errors; Platform/firmware errors | Review the referenced kernel/WHEA events; Correlate timestamps with test activity |
| BE-MEM-001 | error | Memory pattern mismatch | Data read back from an allocated memory buffer did not match the written pattern. | DIMM defect; Memory controller; Unstable memory timings/voltage; Thermal issue | Repeat the pattern test; Test DIMMs individually in a supported slot; Run a preboot memory test for full coverage; Reset memory settings to approved profile |
| BE-MEM-002 | warning | Memory allocation reduced | The requested test buffer could not be allocated; coverage was reduced. | Insufficient free memory; OS memory limits | Close other applications; Use preboot diagnostics for broad coverage |
| BE-MEM-003 | error | ECC errors reported | The memory controller reported corrected or uncorrected ECC errors. | Degrading DIMM; Memory controller; Seating/contact issue | Identify the reporting channel/DIMM; Reseat or replace the DIMM with power removed; Repeat memory testing |
| BE-STO-001 | error | Scratch file integrity mismatch | Data read back from the scratch test file did not match what was written. | Storage device error; File system or driver issue; Memory error; Controller/cable issue | Review SMART/NVMe health; Repeat on a different volume; Run memory tests |

| BE-STO-003 | warning | Insufficient scratch space | Free space was insufficient for the requested scratch test size. | Volume full | Free space or choose a dedicated scratch volume |
| BE-STO-004 | warning | Storage error counters non-zero | The device or kernel reported media/integrity errors. | Media degradation; Link/cable errors | Review error log entries; Re-check after reseating |
| BE-GPU-001 | info | GPU backend unavailable | No supported compute/graphics backend is available for this device. | Driver or runtime not installed; Backend not implemented for this vendor | Install the supported driver; See the hardware support matrix |

| BE-GPU-011 | error | GPU device lost or hung | The driver reported device loss, or GPU work did not complete in time. | Driver reset (TDR) or crash; PCIe link/riser fault; Insufficient or unstable power; GPU hardware fault; Overheating | Review system log for driver resets; Inspect riser, seating and PCIe power connectors with power removed; Repeat with the GPU isolated in another slot |
| BE-GPU-012 | warning | GPU memory coverage reduced | The requested VRAM allocation could not be obtained; coverage was reduced. | Other processes using VRAM; Driver allocation limits; 50% heap safety cap | Close other GPU applications; Repeat with a smaller request and document coverage |
| BE-GPU-014 | error | GPU memory mismatch | Data read back from a GPU memory allocation did not match the written pattern. | VRAM defect; GPU core; Driver; Unstable power | Repeat independent GPU test; Review ECC counters; Compare with a known-good configuration |
| BE-GPU-020 | warning | GPU telemetry incomplete | Required GPU telemetry was not available from the supported interface. | Driver does not expose metric; Unsupported GPU | Document as unavailable; do not run high-load GPU profiles without required sensors |
| BE-PCIE-001 | warning | PCIe link below capability | The negotiated PCIe link speed or width is lower than the device's maximum. | Idle power-saving downshift (may be normal); Riser/slot signal integrity; Slot wiring limits; Device seating | Re-check under controlled load; Compare against approved configuration manifest; Inspect riser and seating with power removed |
| BE-PCIE-002 | error | PCIe link below manifest | The negotiated link is below the value required by the approved configuration manifest. | Riser/cable; Slot; Device seating; Firmware setting | Hold unit; Inspect riser and seating with power removed; Repeat after reseat |

| BE-GPU-030 | error | GPU rendering inconsistency | Re-rendering an identical reference frame produced different pixels. | GPU core or VRAM instability; Driver defect; Overheating; Power instability | Repeat the graphics test; Run compute and VRAM tests; Check temperatures and throttling during load |
| BE-PCIE-004 | warning | PCIe replay counter increased | Link-level retransmissions (replays) increased during the test, indicating signal-integrity errors that were corrected. | Riser or cable signal integrity; Slot contact; Link speed beyond channel capability | Inspect and reseat the riser and GPU with power removed; Repeat under load; Compare against a known-good riser |
