BE Validation `v0.1.0-alpha` is the first downloadable development build of the Ballin Electric System Validation Suite. It is meant for evaluation and for bringing up physical hardware.

## Downloads

| File | Contents |
| --- | --- |
| `BE-Validation-v0.1.0-alpha-windows-x64-portable.zip` | Windows x64 portable edition: desktop GUI, command line, isolated worker, profiles and documentation. Built with MSVC and a static C runtime, so no Visual C++ Redistributable is needed. |
| `BE-Validation-v0.1.0-alpha-linux-x86_64.tar.gz` | Linux x86_64 portable archive |
| `be-validation_0.1.0~alpha_amd64.deb` | Debian/Ubuntu package (installs to `/opt/be-validation`) |
| `SHA256SUMS.txt` and `*.sha256` | SHA-256 checksums. Without a code signature they show integrity only, not authenticity. |

Installation, operation and SmartScreen notes are in `docs/Windows Development Build.md`, included in the ZIP.

## What works

- Read-only hardware inventory and capability registry. Linux: sysfs/procfs. Windows: CIM. NVIDIA: NVML when the driver is installed.
- Low-impact known-answer diagnostics:
  - CPU: NIST SHA-256, Lucas-Lehmer and exact FMA checks;
  - RAM: eight pattern types;
  - storage: scratch-file integrity.
- Reviews: sensors, hardware error logs, PCIe, network, firmware, SMART and GPU inventory.
- Isolated worker processes with timeouts, heartbeat watchdog, operator Stop and a safety supervisor.
- Manufacturing records, inspection sign-off, release policy, audit log, and HTML/JSON/CSV reports.
- Industrial desktop GUI and the `bevalidate` CLI.

## Known limitations

- **Not validated on physical BE-01 hardware or on any physical workstation.** Windows builds are tested on GitHub's Windows Server 2022 CI runners only.
- GPU compute, VRAM and graphics stress tests are not included in this build. They report UNSUPPORTED.
- Stress tests require an approved, device-specific safety profile. None is included.
- See `docs/Known Limitations and Troubleshooting.md` and `docs/Physical Hardware Testing Guide.md`.
